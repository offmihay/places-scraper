# Documentation index

This folder is the source of truth a fresh contributor (human or AI)
should read before touching the code. The top-level [README](../README.md)
only covers what the project is and how to run it; everything below
explains why it's built the way it is.

Read in order on first visit; come back to individual files later as
reference.

| File                                       | When to read                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------- |
| [01-product.md](./01-product.md)           | What the product does, who it's for, what a user flow looks like. Start here. |
| [02-architecture.md](./02-architecture.md) | Three services, two queues, an event bus, why those choices.                  |

If you're an AI assistant picking the repo up cold: read 01 → 02 in
order, then explore the source — those two files explain the why,
the code shows the how.
